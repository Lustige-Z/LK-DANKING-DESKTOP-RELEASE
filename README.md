# 蛋神助手电脑版

当前版本：**1.2.0** · Windows

本仓库用于发布电脑版安装包、更新公告和下载说明。

## 下载新版

- [GitHub 最新发行版](https://github.com/Lustige-Z/LK-DANKING-DESKTOP-RELEASE/releases/latest)
- [国内镜像下载](https://danking.cn/desktop/)

下载发行版中的 `.exe` 文件后运行。首次采集按教学引导安装 Npcap，并先开启采集，再登录游戏角色。程序需要 Windows 与 WebView2。

旧版用户会通过原更新通道收到 1.2.0 提示。支持差分更新的已有正式版本优先下载补丁；不匹配的版本可下载完整文件。退出旧程序后使用新版，个人资料继续保存在原本机数据目录。

## 更新公告

[查看 1.2.0 更新公告](CHANGELOG.md)。应用内公告在首次教学结束后显示，也可从侧栏“更新公告”打开。

GitHub 与国内镜像提供相同的安装包，SHA-256 见 `SHA256SUMS.txt`。
